# 📊 Agent Performance Dashboard | Microsoft Excel

An interactive Microsoft Excel dashboard designed to monitor and evaluate sales agent performance. The dashboard provides comprehensive insights into revenue, profit, conversion rates, regional performance, product profitability, and agent productivity using PivotTables, PivotCharts, slicers, and Excel formulas.

---

## 📖 Project Overview

This project transforms raw sales and agent performance data into an interactive dashboard that enables managers and business stakeholders to monitor key performance metrics, identify top-performing agents, evaluate regional sales, and make informed business decisions.

The dashboard provides a centralized view of sales performance with interactive filtering by month.

---

## 🎯 Business Objectives

- Monitor agent performance across different regions.
- Evaluate revenue, profit, and operational costs.
- Track sales conversion rates.
- Identify top-performing sales agents.
- Compare regional sales performance.
- Analyze product profitability.
- Support business decisions using interactive reports.

## 💡 Key Insights

- The North region generated the highest revenue.
- Several agents consistently outperform others in both revenue generation and deals closed.
- The average conversion rate across all agents is 49%.
- Health Plan and Home Insurance products contribute significantly to profitability.
- Revenue varies across products, highlighting opportunities for strategic focus.
